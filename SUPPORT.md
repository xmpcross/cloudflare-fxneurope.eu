# Support

Thank you for purchasing Synth.

## Updates

A valid license includes lifetime access to theme updates, as described in [LICENSE](./LICENSE). Use the update channel provided with your purchase to download newer versions.

## Included Support

Support covers:

- Installation guidance for a clean copy of the theme.
- Build errors caused by the unmodified theme.
- Questions about documented customization points.
- Bug reports for theme components, routes, styles, and metadata.

## Not Included

Support does not include:

- Custom design or feature development.
- Migrating existing sites or content.
- Debugging third-party services, analytics, ad networks, newsletter providers, or hosting accounts.
- Legal review of privacy, cookie, advertising, or editorial policies.

## Before Requesting Support

Please include:

- Your Node.js and npm versions.
- The command that failed.
- The full terminal error.
- Any changed files related to the issue.
- Whether the issue happens in a fresh copy of the theme.

Run these commands first:

```bash
npm install
npm run release:check
```
